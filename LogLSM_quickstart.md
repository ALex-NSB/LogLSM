## Проект

- **Путь на диске:** `D:\AIPrj\LogLSM`
- **GitHub:** https://github.com/ALex-NSB/LogLSM (публичный, автор ALex-NSB)
- **Что это:** регистратор LogLSM — STM32 (прошивка) + Qt-приложение
  LOGLSMW (`SoftWare/LOGLSMW`) для управления/мониторинга. Датчики
  гироскоп+акселерометр, NOR Flash для записи данных.
- **Резервные копии/архивы** (zip/rar) хранятся ОТДЕЛЬНО от репозитория:
  `D:\AIPrj\LogLSM_backups` — в git их быть не должно.

## Стандартный порядок работы с git

Терминал (cmd) в папке проекта:

```
cd /d "D:\AIPrj\LogLSM"
git status > status.txt
notepad status.txt
```

Дальше — прислать `status.txt` (как файл, не скриншот) для разбора.

Типовая последовательность фиксации изменений:

```
git add -A
git status
git commit -m "Краткое описание изменений"
git push
```

## Известные грабли (уже проходили)

- `cd` с диска C: на D: требует ключ `/d`: `cd /d "D:\AIPrj\LogLSM"`.
- В именах папок/файлов возможны похожие кириллица/латиница символы —
  если `cd` не находит путь, набирай начало имени и жми **Tab** для
  автодополнения, не вводи вручную.
- Узкое окно cmd переносит строки и путает вывод — либо разворачивать
  окно на весь экран, либо перенаправлять в файл (`> status.txt`) и
  присылать файл целиком.
- Архивы (.zip/.rar) в git не коммитим — переносить в
  `D:\AIPrj\LogLSM_backups` (можно вручную через проводник).
- Периодически появляются мусорные нулевые файлы с именами вроде
  `(c)`, `git`, `modified` — это не часть проекта, можно удалять.
