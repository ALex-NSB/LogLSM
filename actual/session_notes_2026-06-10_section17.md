## Решения принятые в этой сессии

### 1. Формат LTP-пакета ✅ ЗАКРЫТО

```
FEND | VER | ADDR | SERVICE | CMD | FLAGS | SEQ16 | LEN16 | PAYLOAD | CRC16
```

- FEND = 0xC0, FESC = 0xDB, TFEND = 0xDC, TFESC = 0xDD (SLIP framing)
- VER = версия протокола (1 байт)
- ADDR = адрес устройства (1 байт)
- SERVICE = идентификатор сервиса (1 байт) — первый уровень адресации
- CMD = команда внутри сервиса (1 байт) — второй уровень
- FLAGS = флаги (1 байт)
- SEQ16 = порядковый номер (2 байта, little-endian)
- LEN16 = длина PAYLOAD (2 байта, little-endian)
- PAYLOAD = полезная нагрузка (LEN16 байт)
- CRC16-CCITT: poly=0x1021, init=0xFFFF, no reflect, xor=0x0000

**Двухуровневая адресация SERVICE+CMD** выбрана намеренно — удобнее для расширения команд.

> ⚠️ CLAUDE.md и `LTP_PROTOCOL.md` содержат СТАРЫЙ формат без VER и SERVICE — нужно обновить.

### 2. Режимы питания ✅ ЗАКРЫТО

| Режим | Реализация | Ток | SRAM |
|---|---|---|---|
| PASSIVE | Shutdown | ~0.2 мкА | ❌ теряется |
| WORK (паузы между циклами) | Stop2 | ~20 мкА | ✅ сохраняется |
| WORK (активный цикл) | Run | норма | ✅ |
| SERVICE | Run | норма | ✅ |

PASSIVE = Shutdown (не Stop2!) — медленный старт, потеря SRAM, минимальный ток.
Паузы в WORK = Stop2 — SRAM сохраняется, быстрый старт, умеренный ток.

---

### 3. Скорость UART ✅ ЗАКРЫТО

| UART | Скорость | Применение |
|---|---|---|
| USART2 (XP2, сервисный кабель) — дефолт | **115 200 бод** | Команды, данные, обычный обмен |
| USART2 (XP2) — высокая скорость | **921 600 бод** | Live стриминг IMU (графики реального времени), быстрое считывание всей Flash (~3 мин для 16 МБ) |
| USART1 → HLK-B40 (BLE) | **115 200 бод** | BLE-эфир |

Обоснование 921600: референс demo от STM работает ~900000; 921600 — ближайший стандартный бод.

> ⚠️ Расхождение в файлах: `session_notes_2026-06-10_firmware_start.md` в разделе констант написано `57600 бод` — это УСТАРЕВШЕЕ значение из Qt приложения CtrlRVZD. Актуально: **115200 дефолт**, **921600 для стриминга**.
> `cubemx_config_LOGLSMA+MA00.md` — 115200 ✅ верно.
