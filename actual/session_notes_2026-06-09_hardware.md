## 2. Именование модулей — ФИНАЛИЗИРОВАНО

| Рабочее название | Правильное обозначение | Расшифровка |
|---|---|---|
| E1 | **MA00** | **M**одуль расширения для контроллера типа **A**, номер **00** |
| — | **MB00** | Модуль расширения для контроллера типа **B**, номер **00** |

MA00 = E1 — одна и та же плата, просто правильное название установлено.

Номенклатура комплектов:
- LOGLSMA + MA00 → **LOGLSMA+MA00**
- LOGLSMB + MB00 → **LOGLSMB+MB00**

Файл `actual/A+E1_pinout_from_schematic.md` — заголовок и сноска обновлены, имя файла не менялось (ссылается на оба источника схем).

## 3. Архитектура питания модуля MA00

| Периферия | Управление питанием | Пин MCU | Тип |
|---|---|---|---|
| BLE (HLK-B40) | VT.1 BSS215P (p-канальный FET) | PB6 / B_PW- (pin 42) | Через силовой ключ |
| TMP117 (термодатчик) | T_PWR | PB4 (pin 40) | Прямое GPIO |
| FRAM (FM25V10A-G) | M_PWR / "+UF" | PB5 (pin 41) | Прямое GPIO |

Все три периферийных узла отключаемы программно — токи в норме.

## 4. Межплатный разъём XP1. (LOGLSMA ↔ MA00) — 16 контактов

| Пин | Сигнал | От MCU | Назначение |
|---|---|---|---|
| 1 | +VDD | — | Питание |
| 2 | BPWR | PB6 (42) | BLE power (→ VT.1 gate) |
| 3 | BRES | PB7 (43) | BLE reset |
| 4 | GND | — | Земля |
| 5 | LINK | PB12 (25) | BLE LINK |
| 6 | KEY | PA5 (15) | BLE KEY |
| 7 | U1TX | пин 30 | UART1 TX → BLE BLRX |
| 8 | U1RX | пин 31 | UART1 RX ← BLE BLTX |
| 9 | +UT | — | Питание TMP117 |
| 10 | SCL2 | PB13 (26) | I²C2 SCL → TMP117 |
| 11 | SDA2 | PB14 (27) | I²C2 SDA → TMP117 |
| 12 | MISO1 | PA11 (32) | SPI1 MISO ← FRAM |
| 13 | MOSH1 | PA12 (33) | SPI1 MOSI → FRAM |
| 14 | NSS1 | PA15 (38) | SPI1 CS → FRAM |
| 15 | SCK1 | PB3 (39) | SPI1 CLK → FRAM |
| 16 | +UF | PB5 (41) | Питание FRAM (M_PWR) |

## 5. Программная архитектура — модульные драйверы

Принцип: каждый периферийный узел = отдельный модуль с флагом присутствия.
При старте — детектирование, затем включается только то что найдено.

```c
module_ble    { .present = ?, .power_pin = PB6, .uart = USART1 }
module_tmp117 { .present = ?, .power_pin = PB4, .i2c  = I2C2   }
module_fram   { .present = ?, .power_pin = PB5, .spi  = SPI1   }
```

Модуль, которого нет на плате — просто не инициализируется, без падения прошивки.
