## 5. Счётчики перезапусков + шкала активации

- **0x24 RESET_STATS** — сброс журнала iflash (стр.124–126... 124+3); паспорт
  (стр.123) отдельная страница, сбросом НЕ задевается. Решение: простой сброс
  (стирание), wear не проблема (~10k циклов vs десятки активаций).
- **Шкала активации = кликабельные сегменты-кнопки** (ActivationBar::
  sectorClicked, подписи ВНУТРИ сегментов, высота 24): сегмент 1 «Стереть
  память» (NOR-чип, счётчики НЕ трогает), сегмент 2 «Сброс перезапусков».
  Остальные — заполняем слева направо по мере готовности функций. Отдельная
  кнопка убрана. Симуляция: ► при галочке заливает всю шкалу зелёным.
- ОТКРЫТО: реальная общая активация (▶) пока НЕ включает новые сегменты в
  цепочку (шаги 0–5 старой машины).

## 6. Сторожа: IWDG + RTC в паре — ✅ РЕАЛИЗОВАНО (design B, modes_and_timers §3)

- IWDG ~32 c (LSI /256×4095) включается на boot БЕЗУСЛОВНО, БЕЗ заморозки
  (опционный байт не нужен). ⚠ Порядок инициализации как в HAL: KR=CCCC
  (старт, включает LSI) → 5555 → PR/RLR → wait SR → AAAA. Обратный порядок
  ВЕСИЛ прибор (вечный while до main-loop — разобрано, зафиксировано).
- **RTC-wakeup в ОБОИХ ярусах сна**: «Проверка» ~1 c, ПАССИВ ~25 c (<32 c
  IWDG) — глажение сторожа. В Пассиве источник различается по WUF2:
  движение → «Проверка»; только RTC → погладили и спим дальше (гироскоп не
  трогаем, автономность цела).
- Рефреш: главный цикл + Service(). Стирание чипа асинхронное — не мешает.
- **0x26 WDG_TEST** — тест: отключает рефреш → сброс через ~32 c → счётчик
  «по таймеру» +1 (подтверждено: 4→8 за серию тестов). Вызов: дабл-клик по
  строке «по таймеру» на «Данные». Одноразовый (boot включает рефреш заново),
  в поле не мешает — НЕ вырезать.
- Индикация в W: счётчик вырос → моргание значения красным ~10 c; при тесте
  подпись «по таймеру» красная до сброса; **kick-метка 0x25** (unsolicited,
  троттл 20 c, только при кабеле, только «Работа») → моргание «по таймеру» +
  вспышка в шапке «● сторож сброс» ~1.5 c + строка [RX] kick в журнале.
- ⚠ ОТКРЫТО: метка из свежепробуждённого Stop2 (Пассив) НЕ доходит до линии —
  вспышки видны только из бодрых фаз (CONFIRM/ROTATING). Подозреваемый — UART
  сразу после Stop2. НЕ расследовано. Косвенное подтверждение глажения в
  Пассиве: сбросов каждые 32 c НЕТ.
- Режим Работа—Сервис УТВЕРЖДЁН: верх цикла всегда читает WKUP1 (PA0):
  1 = Сервис (слив), 0 = рабочий режим.

## 12. Стенд: терминология циклограммы + строка «Циклов» (обсуждено 19.07, НЕ реализовано)

Уточнена ИЕРАРХИЯ полей циклограммы (пробел, вылезший при обсуждении режима
смен скоростей):
- **«Интервалов»** = число смен скорости ВНУТРИ одного рабочего цикла.
  - N старт/стоп: это число СТУПЕНЕК (N отдельных пусков старт→стоп, на каждой
    своя скорость) — калибровка порога пробуждения.
  - Только +/−/Случайно ±: мотор НЕ останавливается, за один непрерывный цикл
    N раз меняет скорость → регистратор пишет ОДНУ запись на весь цикл.
- **«Циклов»** (ЗАБЫТАЯ строка — ВЕРНУТЬ в группу «Циклограмма испытания») =
  количество РАБОЧИХ циклов (сколько раз прогнать работа→простой). Сейчас
  циклограмма крутится до ручного «Стоп»; с полем «Циклов» — N циклов и стоп.
